# Membangun Aplikasi Manajemen Aset

Dalam ekosistem Next.js modern, kita seringkali harus menghubungkan antarmuka pengguna (Frontend) dengan sumber data (Backend) melalui API. 

Proses ini melibatkan beberapa langkah krusial:
1. **State Management**: Menyediakan wadah di dalam komponen React untuk menyimpan data yang datang dari server.
2. **Lifecycle Hooks**: Mengatur kapan *request* ke server harus dilakukan (biasanya saat komponen pertama kali dirender menggunakan `useEffect`).
3. **HTTP Methods**: Menggunakan metode yang tepat (`GET`, `POST`, `PATCH`, `DELETE`) sesuai dengan tindakan yang ingin dilakukan pengguna.
